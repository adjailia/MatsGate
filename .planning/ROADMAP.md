# ROADMAP.md — MetsGate

## Milestone: Mobile App Launch

### Phase 1: Technical Examination
- فحص MetsGate تقنيًا
- Assess current PWA status
- Identify technical requirements for mobile conversion

### Phase 2: PWA Conversion
- تحويله إلى PWA إذا لم يكن كذلك
- Add manifest.json and service worker
- Ensure offline capability

### Phase 3: Android Project Setup
- إنشاء مشروع Android
- Initialize Android Studio project
- Configure build.gradle

### Phase 4: Web Integration
- ربطه بـ https://metsgate.com/
- Configure WebView to load metsgate.com
- Handle deep linking

### Phase 5: Keystore Creation
- إنشاء keystore
- Generate release keystore for signing
- Store credentials securely

### Phase 6: Build Release AAB
- بناء app-release.aab
- Build Android App Bundle
- Sign with release keystore

### Phase 7: Device Testing
- اختبار التطبيق على هاتف Android
- Test on physical Android device
- Verify all features work

### Phase 8: Play Console Setup
- إنشاء تطبيق MetsGate في Play Console
- Create app listing in Google Play Console
- Configure store presence

### Phase 9: Store Assets Preparation
- تجهيز الأيقونات وScreenshots وPrivacy/Data Safety
- Design app icons (512x512)
- Create screenshots for store listing
- Write privacy policy
- Complete Data Safety section

### Phase 10: Google Play Upload
- رفعه إلى Google Play
- Upload AAB to Play Console
- Submit for review
