# متس غيت - مقارن المنتجات 🛍️

![Mets Gate Logo](../images/LOGO_150.png)

> **متس غيت** منصة حديثة وبديهية مصممة لمقارنة أفضل المنتجات التجميلية والعطور ومستحضرات العناية بالبشرة بأفضل الأسعار.

---

## 🌟 الميزات الرئيسية

### البحث والتصفية
- 🔍 **بحث متقدم:** ابحث عن المنتجات بالاسم أو العلامة التجارية أو الوصف
- 🏷️ **تصفية ديناميكية:** قم بالتصفية حسب العلامة التجارية والفئة
- 💰 **تصفية السعر:** شريط تمرير لاختيار نطاق سعري محدد
- 🏷️ **تصفية التخفيضات:** اعرض المنتجات المخفضة فقط
- 📊 **عداد النتائج:** عدد المنتجات المصفاة يظهر في الوقت الفعلي

### المقارنة
- ⚖️ **قارن في الوقت الفعلي:** حدد وقارن بين عدة منتجات
- 📈 **رسم بياني للأسعار:** تصوير بصري للفرق في الأسعار
- 💵 **حساب التوفير:** يعرض الفرق في السعر بين المنتجات
- 🔗 **مشاركة المقارنة:** أنشئ رابطاً فريداً للمشاركة

### تجربة المستخدم
- 🌙 **الوضع المظلم:** ساحة مريحة للتصفح الليلي
- ❤️ **قائمة الأمنيات:** احفظ المنتجات المفضلة لديك
- 💾 **حفظ تلقائي:** تحديداتك محفوظة تلقائياً (localStorage)
- 📱 **تصميم متجاوب:** متوافق مع الجوال واللوحي والحاسوب
- ⏳ **مؤشر التحميل:** دوران أثناء تحميل البيانات

### تحسين محركات البحث والأداء
- 🎯 **SEO محسّن:** وسوم meta و Open Graph
- ⚡ **التحميل كسول:** تحميل الصور بشكل تدريجي
- 📄 **ترقيم الصفحات:** 20 منتج في الصفحة لأداء أفضل

## 🚀 التثبيت المحلي

### المتطلبات
- Git
- Python 3 (للمحلل المحلي)

### الخطوات

1. **استنساخ المستودع:**
   ```bash
   git clone git@github.com:adjailia/MatsGate.git
   cd MatsGate
   ```

2. **إنشاء ملف JSON (اختياري):**
   ```bash
   node generate.js
   ```

3. **تشغيل المحلل المحلي:**
   ```bash
   python3 -m http.server 8000
   ```

4. **فتح في المتصفح:**
   ```
   http://localhost:8000
   ```
