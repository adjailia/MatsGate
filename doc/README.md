# Mets Gate - Comparateur de produits 🛍️

![Mets Gate Logo](https://raw.githubusercontent.com/metsgate/metsgate.github.io/main/assets/images/logo.png)

> **Mets Gate** est une plateforme moderne et intuitive conçue pour comparer les meilleurs produits cosmétiques, parfums et soins de santé au meilleur prix.

---

## 🌟 Fonctionnalités (Features)

- 🔍 **Recherche Avancée :** Recherchez facilement vos produits par nom, marque ou mots-clés.
- 🏷️ **Filtrage Dynamique :** Filtrez les articles par marque (ex: *Bioderma*) et par catégorie de soin.
- ⚖️ **Comparateur en Temps Réel :** Sélectionnez et comparez plusieurs produits côte à côte.
- 📱 **Design Responsive :** Une interface fluide adaptée aux mobiles, tablettes et ordinateurs.
- ⚡ **Performance & Sécurité :** Optimisé via Cloudflare DNS & Caching pour un chargement ultra-rapide.

---

## 🛠️ Technologies Utilisées (Tech Stack)

- **Frontend :** HTML5, CSS3 (Modern Flexbox & Grid), JavaScript (Vanilla ES6)
- **Hébergement :** GitHub Pages
- **DNS & CDN / Sécurité :** Cloudflare
- **Icons & Typography :** FontAwesome / Google Fonts

---

## 🚀 Lancer le projet en local (Local Setup)

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/metsgate/metsgate.github.io.git
   ```

2. **Accéder au dossier :**
   ```bash
   cd metsgate.github.io
   ```

3. **Ouvrir dans le navigateur :**
   Vous pouvez ouvrir le fichier `index.html` directement ou utiliser un serveur local (ex: Live Server dans VS Code / `python3 -m http.server 8000`).
